# Diagramas editables

Abrir los archivos `.drawio` con draw.io / diagrams.net mediante Archivo > Abrir
desde > Dispositivo. Los nodos corresponden a los componentes y funciones reales
del proyecto. En las diapositivas se mantienen versiones editables de estos flujos.

1. Arquitectura y papel del celular Android (hotspot).
2. Solicitud y retorno del video MJPEG.
3. Registro de una persona en el padrón.
4. Capturas y reporte por correo.

El ESP32-S3 no ejecuta Android. El celular proporciona conectividad de red.
